Try it on your phone

  1. Open github.com/mukesh9871/motionloop/actions, pick the newest green run, and download motionloop-debug-apk (a zip).
  2. Unzip it and copy app-debug.apk to the phone (USB, Drive, or email to yourself).
  3. Tap the file on the phone. Android asks to allow installs from that app (Files or Drive): allow it once.
  4. Open MotionLoop, pick a photo, drag arrows on water or clouds, press play, then Export.

On your personal laptop with Android Studio: clone the repo, run gradle wrapper --gradle-version 9.6.0 once (or let Studio offer it), then Run on a USB-connected phone with USB debugging on.

What I could not verify

Nothing has run on a device or emulator yet. CI proves the code compiles and the unit tests pass (loop timing, GIF encoder round trips, LUT parsing, overlay settings). It cannot show visual quality, export playback on real encoders, or touch handling. Please send screenshots or a short screen recording of anything that looks wrong.

Decisions for you

Start Phases 4 to 6? Sky replacement, 3D parallax, tap-to-select masking, background removal and text behind subject all need on-device ML models (MediaPipe segmenters, a depth model) added to the project. I stopped before downloading any.

Short slow exports. A clip must contain whole loop cycles to be seamless, so a 3 s export at speed 0.25 plays faster than the preview. Options: lengthen the clip to one full cycle, or keep the length and show the real speed in the export sheet.
